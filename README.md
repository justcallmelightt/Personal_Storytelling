# Personal Storytelling

사람마다 자신의 시간을 독립적인 페이지로 꾸미고, 하나의 이야기로 공유하는 개인 스토리텔링 MVP입니다.

## Stack

- Next.js App Router
- React + TypeScript/TSX
- Tailwind CSS
- Motion for React
- LocalStorage 기반 MVP 저장

## Run

```bash
npm install
npm run dev
```

`mvp` 브랜치는 편집 경험을 검증하는 단계입니다. 사용자 계정, 이미지 업로드, 공유 URL은 다음 단계에서 Supabase로 연결합니다.
